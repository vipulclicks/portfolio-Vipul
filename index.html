pHinder: pH Made Simple

A chemistry education app that makes pH concepts intuitive.

The Problem

Understanding pH and acid-base chemistry is a challenge for many students. Existing educational tools are either overly simplistic or buried in textbook-style interfaces that don't engage learners. pHinder reimagines chemistry education with an interactive, visually rich iOS experience.

Key Features

  • Interactive pH scale with real-time calculation feedback
  • Guided onboarding using TipKit for progressive feature discovery
  • Visual acid-base indicator simulations
